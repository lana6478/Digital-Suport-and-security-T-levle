# Core Component Overview

*Digital Support and Security T Level → Core Component*

The **Core Component** is the shared foundation every student studies, regardless of which Occupational Specialism they go on to choose. It covers the underpinning knowledge, concepts and skills that support **threshold competence** across the whole digital industry, and is assessed through two written exam papers plus an Employer Set Project.

## Purpose

The Core Component exists to build the knowledge base that every digital role — infrastructure, cabling, support, or security — draws on: problem-solving, understanding how digital systems and data work, legislation and regulation, the business context digital work happens in, emerging technology issues, digital environments, and security fundamentals. Where a student's chosen Occupational Specialism goes deep on one occupational area, the Core Component gives them the shared vocabulary and thinking tools to operate across the sector.

## The Core skills

The specification identifies six **core skills**, mapped across the Core content wherever there's a natural opportunity to develop them. They aren't taught as one-off lessons — they're built up through the course content, then directly assessed via the **Employer Set Project**:

1. Be able to reflectively evaluate
2. Communicate information clearly to a technical and non-technical audience
3. Work with stakeholders to consider options to meet requirements
4. Develop software / create an artefact
5. Apply a logical approach to solving problems — identify and resolve faults, propose a solution to a digital support problem
6. Ensure activity mitigates risks to security

## Structure

The Core Component has three assessed parts:

| Part | What it covers | Weighting |
|---|---|---|
| [Core Paper 1](01-core-paper-1.md) | Problem solving · Introduction to digital support · Data | 30% of core (15% of total) |
| [Core Paper 2](02-core-paper-2.md) | Legislation and regulation · Business context · Emerging issues · Digital environments · Security | 30% of core (15% of total) |
| [Employer Set Project](03-employer-set-projects.md) | A substantial, externally set project synoptically assessing the six core skills | 40% of core (20% of total) |

Together, the Core Component makes up **50% of the total qualification** — the other 50% comes from the student's chosen [Occupational Specialism](../02-occupational-specialisms/00-overview.md).

For exact exam durations, mark totals and Assessment Objectives, see [Core scheme of assessment](04-core-scheme-of-assessment.md).

## Key terms

- **Threshold competence** — having the core knowledge and skills needed to be ready to build full occupational competence on the job.
- **Core skills** — the six cross-cutting skills (above) assessed synoptically through the Employer Set Project.
- **Synoptic assessment** — assessment that draws together knowledge/skills from across the whole component, rather than testing isolated topics.
