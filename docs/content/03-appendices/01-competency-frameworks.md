# General Competency Frameworks

*Digital Support and Security T Level → Appendices*

Alongside the technical content, every T Level embeds a **General Competency Framework** covering English, maths and digital skills. This page lists the competencies relevant to Digital Support and Security, plus the command word taxonomy used across the assessments. Where a specification content point can help develop one of these competencies, it's signposted with the competency's short code (e.g. **E1**, **M6**, **D5**) next to that point in the Occupational Specialism content.

These competencies are embedded in **both** the Core Component and the Occupational Specialism Component - they aren't a bolt-on, they're meant to be developed through the normal course content, with teachers looking for natural opportunities to build them in.

## Command word taxonomy

Assessments use a consistent set of **command words** so students know exactly what kind of response is expected. This list is for guidance - not every paper uses every command word.

| Command word | What it requires |
|---|---|
| Give / state / name | Provide a response - e.g. a feature, characteristic, use, or justification of something. |
| Identify | Select the correct answer from the given context or stimulus. |
| Write | Write a formula using information from the given context or stimulus. |
| Describe | Provide responses linked together in an appropriate, logical order. |
| Explain | Identify a point, and give a linked justification for that point. |
| Explain with additional justification | Identify a point, give a linked justification, then a further justification that builds on the first. |
| Discuss | Weigh up the factors relevant to a specific context, giving careful consideration to opposing aspects of an issue, situation or problem. No conclusion is required. |
| Evaluate | Consider various aspects of a subject's qualities - strengths/weaknesses, advantages/disadvantages, pros/cons - and reach an evidence-supported judgement, usually as a conclusion. |
| Draw | Produce a diagram (e.g. an algorithm, a process flow) using information from a given context or scenario. |
| Complete | Fill in the missing information on a diagram so it's fully correct and complete. |

Understanding this list matters as much as knowing the content itself: an "Explain" answer that only *describes* (without justification) or a "Discuss" answer that jumps straight to a conclusion will lose marks regardless of how accurate the underlying knowledge is.

## Key terms

- **Signposting** - marking specific content points with a competency code (E/M/D + number) to show where that skill is naturally developed.
- **Command word** - the instructional verb in a question (e.g. "Evaluate", "Identify") that defines what kind of answer is required.
