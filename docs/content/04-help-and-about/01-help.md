# Help: Using This Wiki

*Digital Support and Security T Level → Help*

This page explains how to get around the site - how search works, how the sidebar and breadcrumbs work, and how the wiki relates to the file library in the GitHub repository.

## Searching

Use the search box at the top of every page. It searches the **title and full text of every page** as you type, not just headings - so searching for a specific term (e.g. "CVSS", "patch panel", "phishing") will surface any page that mentions it, even if it's not in the title. Matching words are highlighted in the results, and each result shows a short snippet of surrounding text plus its file path so you know exactly where it lives.

## The sidebar directory tree

The panel on the left mirrors the `content/` folder in the GitHub repository exactly - same folders, same files, same order. Click a folder name to expand or collapse it; click a page name to open it. Whatever page you're currently reading is highlighted in the tree, and its parent folders are automatically expanded, so you always know where you are.

On narrow/mobile screens, tap the &#9776; button in the top-left to show or hide the sidebar.

## The breadcrumb and "Contents" box

Above every article title is a **breadcrumb** showing the folder path to that page (e.g. `content / occupational-specialisms / cyber-security / ...`) - click any segment to jump to that folder. Longer articles also get an automatically generated **Contents** box under the introduction, listing every section on the page as a jump link - exactly like the contents box on a Wikipedia article.

## Categories

At the bottom of each article you'll see a **Categories** line - this shows which part of the qualification the page belongs to (e.g. Core Component, or a specific Occupational Specialism), and clicking a category takes you to that section's overview page.

## Files vs. website

Everything on this site is generated directly from the markdown files in the repository's `content/` folder, so the two are always in sync. If you'd rather read the raw files - for example, to search across everything at once with your own tools, or to download the whole library - you can browse `content/` directly on GitHub instead of using the site. See the [main README](https://github.com/lana6478/Digital-Suport-and-security-T-levle#readme) for a guided starting point.

## This isn't the official specification

This wiki is an independent, unofficial study guide. It paraphrases and reorganises the real T Level specification to make revision easier, but it is **not** the exam board's own document, and it can contain mistakes or fall out of date. For anything that actually matters for your assessment - exact wording, mark schemes, deadlines - always check the [official specification](https://qualifications.pearson.com/content/dam/pdf/TLevels/digital-support-and-security/2025/specification-and-sample-assessment-materials/digital-dss-specification.pdf) and your course provider. See [Sources and Further Reading](../sources-and-further-reading.md) for more official links.

## Key terms

- **Breadcrumb** - the folder-path trail shown above an article, letting you jump back up to any parent folder.
- **Contents box** - the auto-generated list of a page's own section headings, shown near the top of longer articles.
- **Category** - the section of the qualification a page belongs to, shown at the bottom of the article and in the folder tree.
